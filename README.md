## About Bakasana

Bakasana helps you log every practice, join challenges, compete with friends, and climb the leaderboard.

Brand line: *Build a yoga practice you want to return to.*

Closing line (all surfaces): *Find your balance. Keep going.*

Shared product and expert copy lives in `[_data/brand.yml](_data/brand.yml)`.

The app supports five paths, plus Free Training:


| Program           | Focus                     | Experience                                                                       |
| ----------------- | ------------------------- | -------------------------------------------------------------------------------- |
| **Bakasana**      | Balance and concentration | Train balance, focus, and confidence toward crow pose.                           |
| **Plank**         | Strength and endurance    | Develop the full-body foundation behind a stronger practice.                     |
| **Down Dog**      | Hold                      | Lengthen the spine, build shoulder strength, and hold a steady inverted V.       |
| **Flow**          | Free-form movement        | Practice through your own session with optional clip capture.                    |
| **Shavasana**     | Recovery and meditation   | Follow guided voice sessions and make rest part of regular practice.             |
| **Free Training** | Any other session         | Log pilates, calisthenics, boxing, cycling, or anything else so it still counts. |
